## 2026-11-06 — Светящаяся точка бежит по контуру иконки агента

- Кнопка чата в билдере: по внешнему контуру иконки агента бежит светящаяся точка с хвостом (цикл 3,6 с). ## 2026-11-06 — Баг: карточки с координатой 0 смещались при открытии агента

- Причина: `importGraphInner` в `builder.js` писал `node.x || 80 + index * 40` — сохранённый 0 считался «пусто» и заменялся значением по умолчанию. Раскладки из окна «Упорядочить» (первая карточка в 0,0, колонки с x=0) при следующем открытии смещались; страница при этом не считалась изменённой (`markSaved` берёт уже сдвинутое состояние), и следующий Save записывал сдвиг в БД.
- Исправлено: по умолчанию подставляется только отсутствующая (нечисловая) координата. Проверено на «Тикет в Telegram» (в графе 0,0 и 325,0…): положения в редакторе совпали с сохранёнными.
- Не восстановлено: агенты, которые уже были пересохранены после сдвига, остаются со сдвинутыми координатами — раскладку надо выбрать заново.
