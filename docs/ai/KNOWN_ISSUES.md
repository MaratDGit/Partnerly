## KI-016 — Агенты: что осталось после миграции 2026-11-06

- **Статус:** частично закрыто (2026-11-06). Хранилище данных, «Only once» (защита от дублей), теги и «кто менял последним» сделаны (миграция `20261106120000_AddAutomationDataStoreAndTags`, применена на локальной БД по разрешению владельца).
- **Осталось:** зашифрованные секреты агента (сейчас только обычные константы `settings.variables`); комментарии на карточках (есть заметки на холсте, но не привязанные к карточке); очистка просроченных записей хранилища (они игнорируются при чтении, но не удаляются).
- **Ограничения новых функций:** циклы не вкладываются; `wait_until` внутри цикла нельзя; в тесте карточки действия с побочным эффектом не выполняются; уведомление о сбое — только внутри приложения (не письмо); параллельные ветки и слияние работают через рёбра (карточка ждёт все входы), отдельной карточки «Merge» нет; «Only once» в тест-запуске не занимает ключ.
- **Не проверено в браузере** на реальных страницах под входом (нужен вход владельца): проверен только каркас редактора на тестовой странице и юнит-тесты движка. Другие стенды / прод: миграцию не применять без отдельного ок.
- **Журнал:** WORK_LOG 2026-11-06.

## KI-018 — Интеграции: ограничения v1 (ранее второй KI-014)

- **Статус:** открыто (2026-11-03)
- **Суть:**
  - Ключи Data Protection не сохраняются явно (`AddDataProtection()` без `PersistKeysTo…`). На сервере их потеря сделает токены всех подключений нечитаемыми (D5 плана).
  - Курсор опроса и результат шага агента сохраняют payload одного подключения целиком — при одновременной записи один из них может перезаписать другой (редко, курсор откатится на один проход).
  - Реальные вызовы Telegram / Google / Meta не проверялись — только fake HTTP в тестах.
  - До 2026-11-04 лог `HttpClient` писал URL с токеном Telegram в консоль (исправлено фильтром логов). Клиент Automation `AutomationOutbound` (HTTP request / webhook) по-прежнему логирует URL на Information — секреты в query строке туда попадут.
  - WhatsApp-входящие требуют публичный URL; Gmail `history` ≈ неделя — при долгой остановке курсор сбрасывается на «сейчас».
- **Компоненты:** `Partnerly/Integrations`, `AutomationServiceCollectionExtensions`
- **Журнал:** WORK_LOG 2026-11-03 — интеграции

## KI-015 — Webhook: ограничения v1

- **Статус:** открыто (2026-11-04)
- **Суть:** нет защиты от повторной отправки (replay): подпись только по телу, без метки времени; запрос с верной подписью можно повторить. Ответ 404 для неизвестного id и 401 для неверной подписи позволяет проверять существование id. Менеджеры в попапе «Подключения» видят секреты webhook чужих агентов. Подпись считается от тела, прочитанного как UTF-8.
- **Компоненты:** `AutomationWebhookIngestService`, `WebhookSignature`, `AutomationController.BuildConnectionsAsync`
- **Журнал:** WORK_LOG 2026-11-04 — Подключения / webhook / монитор
